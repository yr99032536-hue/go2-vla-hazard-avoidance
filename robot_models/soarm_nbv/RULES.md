# SO-ARM NBV Project Rules

이 규칙은 이 프로젝트를 수행하는 모든 AI 에이전트가 **절대적으로** 준수해야 하는 최상위 원칙입니다.

1. **절대 스스로 발명하지 말 것 (No Reinventing the Wheel):**
   - 코드를 임의로 새로 짜거나 수학 공식을 스스로 만들어내려고 시도하지 마십시오.
   - 무조건 인터넷 서치를 먼저 수행하고, HuggingFace LeRobot 등 **"기존에 전 세계 사람들이 만들어 둔 공식 라이브러리 및 코드"**를 활용하는 방안을 최우선으로 제안하십시오.

2. **최후의 수단으로만 제안할 것:**
   - 인터넷 서치 결과나 공식 지원 기능이 **완전히 없을 때만** 커스텀 코드를 스스로 작성하는 것을 제안하십시오.

3. **Isaac Sim과 GPU/Vulkan 자원 안정성을 최우선으로 할 것:**
   - `/home/iy/Isaac/AGENTS.md`의 `Isaac Sim / GPU / Vulkan 안정성 하드 규칙`을 항상 적용하십시오.
   - Isaac Sim은 동시에 하나만 실행하고, 반복 실행 사이에는 관련 프로세스가 모두 종료되고 VRAM이 기준치로 회복됐는지 확인하십시오.
   - 자원 회복이 확인되지 않으면 다음 시뮬레이션을 시작하지 마십시오.

4. **Isaac 실행 중 이미지 폴더나 무거운 시각화를 열지 말 것:**
   - Isaac, RViz 또는 GPU 시뮬레이션이 실행 중일 때 대량 이미지 폴더를 파일 관리자로 열거나 ChatGPT/Codex 화면에 여러 이미지를 렌더링하지 마십시오.
   - 시뮬레이션 종료와 GPU 회복을 먼저 확인한 뒤 대표 이미지 한 장만 검사하십시오.

5. **반복 수집은 안전 게이트를 통과할 것:**
   - 각 lap/seed 사이에 Isaac·RTAB-Map·RViz·수집기 프로세스의 종료와 `nvidia-smi` VRAM 회복을 확인하십시오.
   - 회복 실패, Vulkan 오류, VRAM 증가 또는 UI 프리즈 징후가 있으면 batch를 즉시 중단하십시오.
